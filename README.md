# Encuesta de Seguimiento Institucional y Mejora Continua · UNIFRANZ

Encuesta para estudiantes (Encuesta Estudiantes + Encuesta RRDDTT) con acceso por correo institucional,
padrón administrable desde Google Sheets y resumen automático.

- `index.html` — la app que se publica (GitHub Pages).
- `src.html` + `build.py` — fuente de la app y generador de `index.html`.
- `apps-script/Codigo.gs` — backend y menú «Encuesta» para la hoja.

Detalles, decisiones y pendientes: ver `CLAUDE.md`.
